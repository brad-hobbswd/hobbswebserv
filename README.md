## Search Engine Visibility

Crawler access is blocked in `robots.txt` and the sitemap intentionally contains no public URLs while the project remains unlaunched.

**Important:** `robots.txt` is a crawler instruction, not an access-control mechanism. It does not make a public GitHub repository or GitHub Pages site private. For genuine confidentiality, change the repository visibility to private and do not publish a public GitHub Pages site until launch.
